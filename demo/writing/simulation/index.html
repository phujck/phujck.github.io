From a simulation to a manuscript figure

In The Cost of Complexity, the price assigned to a cut decides whether every round of subdivision costs the same. This numerical check of Figure 3 splits every square into four and adds up the cuts, and its output supplies the points of a figure in the manuscript.

In four rounds the program splits 85 parent squares. Priced by area, each round adds one unit. Priced by wall length, the rounds add 1, 2, 4 and 8.

Inspect or reproduce the calculation

Save the code and inputs in the same folder and run the command below with Python 3. The resulting CSV and JSON match the recorded run byte for byte.

python3 subdivide.py --mode smoke --args-json '{}' --result replay/result.json

Run the simulation

The program visits each parent square. It charges its area under one pricing rule and the length of its dividing walls under the other, and saves the totals of each round.

Inspect the numerical result

The completed run records 256 cells, 85 splits and totals of 4 and 15, and its result is linked to the claim about pricing by area. From that result the interface opens both the five-row table and the record of the inputs and code that produced it.

Link the figure to its evidence

The plot takes its two series from the CSV of the run. Beneath it, Linked results names the recorded calculation. The table and the attached result each have a revision check of their own.

Place the computed figure in the manuscript

Place in manuscript inserts the plot after the paragraph on the calculation, with a caption, and the manuscript rebuilds from that source. The published Figure 3 remains the reference for this separate check.

The figure remembers its input

A single extra newline changed the fingerprint of the CSV while leaving every number the same. The interface marked the drawing and its evidence for review, with the old run, the rendered figure and the manuscript still intact. Restoring the original bytes made both checks current again.
