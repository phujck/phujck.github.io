An integrated research environment for people and AI agents.

A network of state machines keeps claims, calculations and sources connected as they change. A diffusion-based memory finds the evidence an agent may open. In the Writing App, the author and agent can work at the same time on the same versioned research project.

Inside a conceptric

What does one claim depend on?

In the paper’s physical model, a register holds distinguishable positions. Picture the positions as places in a square. The first round divides one square into four. The second round divides all four. If splitting a square costs its area, each small square costs a quarter as much to split. Four splits at a quarter of the price give the same total.

Under area pricing, every round of subdivision costs the same.

A conceptric is a relational container. This one holds the claim above. Its exterior links to the section it belongs to, the pricing assumption it requires and the figure that supports it. Following a link opens another container. The same tools work again inside it.

Each container is also a state machine. The tools on it are verbs. A reader can inspect the source. An editor has another permitted action, proposing a correction against the version just inspected. When the source changes, a dependent review can go stale even while the manuscript sentence stays exactly as it was.

One claim, several relationships

The claim about equal cost per round belongs to a section, requires an assumption about how a division is priced, and is illustrated by Figure 3. Opening the section, then the claim, then its grounds uses the same operation at successively finer scales.

Changing a recorded input leaves a trail to the work that consumed it. Looking up the pricing rule brings back the relevant passage and figure. The researcher decides how the manuscript should change.

Recursive memory · Query diffusion

How does a question find its evidence?

Seen from outside, a chapter is one object in the paper. Open it and there is a graph of sections. Open a section and there is a graph of claims, figures and source passages. This is a recursive graph. A chapter can be searched as a whole before an agent opens anything inside it.

In query diffusion, a question gives weight to possible sources, and some of that weight passes to their neighbours. The branches show where that support has collected. Watch the query move through the tree, first with access to the paper, then with access to figures alone.

What can a network of projects learn?

A question can follow a claim into another project and recover the evidence behind it. The editor can also preserve why an expert corrected a claim. With its source and a test, that judgement could guide a different project.

The Writing App

A shared workspace for author and agent.

The Writing App was built for people and agents to develop a manuscript together. While the author drafts a section, an agent can check the simulation behind a figure or propose changes across several files. The editor and the agent’s tools work on the same research objects. Each proposal names the version the agent read, so the author can compare it with the current draft and choose what to apply.
