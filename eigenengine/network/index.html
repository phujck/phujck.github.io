The research network

A project joins a network as a single object, and opening it shows the same structure inside. Nothing in the way a conceptric, the envelope around one concept, is built asks what it contains: a claim will do, but so will a paper, or a project of a dozen papers. A finished project is therefore cited, searched and revised by the rules that govern its claims.
