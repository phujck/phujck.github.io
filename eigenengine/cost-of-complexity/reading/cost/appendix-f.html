Appendix F — Diophantine search and witness encoding

A set is recursively enumerable when an algorithm can confirm membership of each element, although it may run indefinitely on non-members [54]. The DPRM theorem supplies the polynomial witness relation of Eq. (40) for every such set [55, 56]. The input uu fixes the parameters, and a witness tuple xx certifies membership when D(u,x)=0D(u,x)=0. Once supplied, a witness can be checked by finite polynomial evaluation.

A Diophantine guessing machine consists of the parameter and witness spaces, the polynomial DD, and a family of guess distributions pup_u. Independent guesses find a solution almost surely whenever the satisfying witnesses have positive probability. Exhaustive enumeration is another possible search strategy. These choices implement the same logical relation through different processes.

An invertible Gödelisation of witness tuples preserves the Shannon entropy of a fixed ensemble by relabelling its probabilities. Numerical log-magnitude need not be preserved: Cantor pairing can send (x1,x2)(x_1,x_2) with x1≫x2x_1\gg x_2 to a label of order x12x_1^2 [75]. The probability ranking used in Eq. (44) survives this relabelling. Any apparatus or ancillary memory needed to implement the conversion belongs to the physical account of the process.
